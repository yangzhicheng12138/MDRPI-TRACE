# Public teaching examples

This directory contains 30 attributed Open RN adaptations and eight original MDRPI practice questions, plus their rubrics, applicable review records and browsing metadata. Three additional fictional practice scenarios are defined in `modes/teaching.py`.

Open RN source content retains CC BY 4.0. The supplied teaching adaptations retain CC BY-SA 4.0. Source URLs and author/editor attribution are recorded per item. The project's MIT code license does not replace these content licenses or license linked third-party documents.

Formal study cases, private expansion batches and source PDFs are not included. See [data documentation](../../docs/DATA.md).
