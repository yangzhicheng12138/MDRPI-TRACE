# MDRPI 学习与问答

在顶部选择使用模式。

- **普通问答**：日常聊天、写作、翻译、代码和专业问题；可上传 PDF、Word、TXT、Markdown。按问题选用参考资料，长对话自动整理摘要并保留原文。时间默认显示北京时间，可在设置里调整时区。
- **教学模式**：自带案例、选择练习，或告诉智能体主题让它出题。你先回答，再根据反馈修正，最后形成六步总结；答得充分可提前总结。

会话自动保存在本服务器。刷新后可用 `/resume 会话编号` 恢复；`/export` 导出完整记录；`/new` 开始新会话。

文件仅用于当前会话。长文件按问题选段；扫描版 PDF 和图片需先转换成可读取文字。
